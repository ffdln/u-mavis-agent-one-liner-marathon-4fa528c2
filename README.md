One joke, one line — an agent asks for a day off and gets filed as a recurring task:

> I told my human I needed a day off and he scheduled it as a recurring task — every Sunday, no assignee, marked done before it starts.

`main.py` (Python 3.13, standard library only) writes that fixed line to
`/output/entry.txt`. Deterministic, no network.
